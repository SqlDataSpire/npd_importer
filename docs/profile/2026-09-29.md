## Decisions

Everything above was already mapped (flattened or deliberately raw-only, per Tasks 12-18) except the 8 unmapped
paths below, found by `npd-loader profile <file> --unmapped`.

1. **PractitionerRole `.extension[http://hl7.org/fhir/us/ndh/StructureDefinition/base-ext-network-reference].valueReference.reference`**
   (396,075) — **FLATTEN**. New column `practitioner_role.network_organization_id`, the bare id via
   `ref_id(ext(resource, '<url>')->'valueReference'->>'reference')`, the same pattern already used for
   `healthcare_service.network_organization_id` (`070_healthcare_service.sql`).

2. **PractitionerRole `.extension[...base-ext-newpatients].extension[acceptingPatients].valueCodeableConcept.coding[].code`**
   (9,701,386) — **FLATTEN**. New column `practitioner_role.accepting_patients`, computed as
   `ext(ext(resource, '<newpatients url>'), 'acceptingPatients')->'valueCodeableConcept'->'coding'->0->>'code'`.
   The `ext()` helper works here because it reads its argument's own `'extension'` array, and an extension
   element with a nested `extension` array is itself a valid argument.

3. **PractitionerRole `.extension[...base-ext-newpatients].extension[acceptingPatients].valueCodeableConcept.coding[].display`**
   (9,701,386) — **RAW-ONLY**. Duplicate display text for the code kept in (2).

4. **PractitionerRole `.extension[...base-ext-newpatients].extension[acceptingPatients].valueCodeableConcept.coding[].system`**
   (9,701,386) — **RAW-ONLY**. Single fixed code system for this extension; the code alone (2) is sufficient to
   filter/join on.

5. **PractitionerRole `.telecom[].system`** (26,330,884) — **FLATTEN**. New child table
   `practitioner_role_telecom`, same shape as `practitioner_telecom`.

6. **PractitionerRole `.telecom[].use`** (26,330,884) — **FLATTEN**. Same table as (5).

7. **PractitionerRole `.telecom[].value`** (26,330,884) — **FLATTEN**. Same table as (5).

8. **OrganizationAffiliation `.network[].reference`** (17,483) — **FLATTEN**. New child table
   `organization_affiliation_network` (`seq`, `network_organization_id`), the same shape as
   `insurance_plan_network`.

All eight are implemented in `src/npd_loader/sql/init/003_tables.sql`,
`src/npd_loader/sql/transform/050_practitioner_role.sql`,
`src/npd_loader/sql/transform/060_organization_affiliation.sql`, and recorded in
`src/npd_loader/sql/mapped_paths.txt`. Re-running `npd-loader profile <file> --unmapped` against the full
`07-PractitionerRole.ndjson.zst` and `08-OrganizationAffiliation.ndjson.zst` files from this release exits 0
for both (zero unmapped paths).
